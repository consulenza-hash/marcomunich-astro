## Learnings

- **Docker + Rancher Desktop** è workflow ideale per tool CLI complessi da compilare (evita installazione toolchain nativa 500 MB)
- **musl libc (alpine) vs glibc (debian)**: molte lib GNU-extension (es. `sighandler_t`) non esistono su musl → sempre debian-slim se il source usa signal handling GNU
- **qpdf --decrypt**: risolve il 99% dei "PDF non copiabili" senza dover craccare (user password vuota + owner password rimossa)
- **qpdf --pages ranges**: split efficace ma richiede stima adaptive per target size (page weights sono non-uniformi)
